# پروژه گالری ماشین (Luxury & Sports Car Gallery)
مستندات چالش‌ها و راه‌حل‌های فنی

## ۱. گزارش چالش‌ها و راه‌حل‌ها

| چالش (مشکل) | علت اصلی | راه حل |
| :--- | :--- | :--- |
| خطای ۵۰۰ در API | نام‌گذاری نادرست دیتابیس | ویرایش couchdb.ts و تطبیق نام دیتابیس با CouchDB |
| خطای Export Member | ارجاع به نام قدیمی متغیر | به‌روزرسانی تمام ارجاعات ticketsDB به cars_db |
| خطای کش (Cache) | ماندگاری خطای قبلی در Next.js | ری‌استارت سرور و Hard Refresh مرورگر |
| خطای Rejected در Git | عدم همگام‌سازی محلی و ریموت | استفاده از git pull --rebase |
| قفل شدن Rebase | تداخل فایل‌های سیستمی | لغو عملیات با git rebase --abort و git push --force |

---

## ۲. مراحل انجام پروژه
- ایجاد اتصال به CouchDB با استفاده از nano.
- پیاده‌سازی متدهای GET و POST در API Routes.
- عیب‌یابی و دیباگ یکپارچه برای رفع خطاهای ارتباطی.
